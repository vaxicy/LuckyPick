# LuckyPick - 幸运选择器 🎲

Can't decide? Let luck choose for you.
选择困难？让幸运替你决定。

## ✨ 功能特性

### 核心功能
- 🎯 **多选一决定器** - 输入多个选项，让幸运替你决定
- 🪙 **投硬币模式** - 经典的正反面选择
- 🎲 **骰子模式** - 随机骰子结果
- 🎡 **转盘模式** - 可视化转盘动画
- 📜 **趣味结果文案** - 每次都有不同的趣味提示
- 💾 **常用选择组** - 保存你的常用选项
- 📋 **历史记录** - 查看过去的选择记录
- 🍀 **每日幸运** - 每日随机幸运数字、颜色和建议

### 技术特点
- ✅ Manifest V3 合规
- ✅ Vanilla JavaScript（无框架依赖）
- ✅ Chrome Storage Local（无后端）
- ✅ 支持中英文双语
- ✅ 支持深色模式
- ✅ 可直接发布到 Chrome Web Store

## 📦 安装步骤

### 方法一：从源码安装（开发者模式）

1. **下载代码**
   - 克隆或下载本项目到本地

2. **生成图标**
   - 在浏览器中打开 `icon-generator.html`
   - 点击"下载所有图标"按钮
   - 将下载的3个PNG文件放入 `icons` 文件夹
   - 如果没有 `icons` 文件夹，请手动创建

3. **加载到 Chrome**
   - 打开 Chrome 浏览器
   - 访问 `chrome://extensions/`
   - 开启右上角的"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择本项目文件夹

### 方法二：从 Chrome Web Store 安装（待发布）

> 本扩展即将上架 Chrome Web Store，敬请期待！

## 🚀 使用指南

### 1. 基本使用

1. 点击浏览器工具栏的 LuckyPick 图标
2. 输入至少2个选项
3. 选择模式（随机、投硬币、骰子、转盘）
4. 点击"✨ 帮我决定"按钮
5. 观看趣味动画，等待结果揭晓

### 2. 投硬币模式

- 切换到"🪙 投硬币"模式
- 输入"正面"和"反面"（或 Heads 和 Tails）
- 点击决定按钮，观看硬币翻转动画

### 3. 保存常用选择组

- 输入常用选项（如：麦当劳、肯德基、必胜客）
- 点击"💾 保存选择组"
- 输入组名（如：午饭吃什么）
- 下次使用时，点击"💾 已保存"按钮，选择对应的组即可

### 4. 查看历史记录

- 点击"📋 历史记录"按钮
- 查看过去的选择结果
- 支持清空历史记录

### 5. 每日幸运

- 每次打开扩展，都会看到今日的幸运信息
- 包括：幸运数字、幸运颜色、幸运建议
- 每天自动更新一次

### 6. 设置

- 点击"⚙️ 设置"按钮
- 可以设置：
  - 语言（中文/English）
  - 主题（浅色/深色）
  - 默认模式
  - 动画开关
  - 历史记录数量限制
